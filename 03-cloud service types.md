# Section 3 – Cloud Service Types

## Purpose of this Section
Understand **how cloud services are delivered**, and how responsibility shifts between the customer and the cloud provider.

## 3.1 Infrastructure as a Service (IaaS)
- Provides basic computing infrastructure
- Includes virtual machines, storage, and networking
- Customer has **maximum control** in the cloud

**Customer manages:**
- Operating system
- Applications
- Data
**Provider manages:**
- Physical datacenter
- Hardware
- Network infrastructure
**Common use cases:**
- Lift-and-shift migration
- Full control over servers

## 3.2 Platform as a Service (PaaS)

- Provides a platform to run applications
- No need to manage servers or OS
- Focus is on **application code**

**Customer manages:**
- Application code
- Data
**Provider manages:**
- OS
- Runtime
- Scaling
- Infrastructure
**Common use cases:**
- Web applications
- API development

## 3.3 Software as a Service (SaaS)

- Ready-to-use software delivered over the internet
- No infrastructure or platform management

**Customer manages:**
- Data
- User access
**Provider manages:**
- Application
- Platform
- Infrastructure
- Security updates
**Common use cases:**
- Email
- Collaboration tools
- CRM systems

## 3.4 Serverless Computing (Concept)

- No server management required
- Pay only for execution time
- Automatically scales based on demand
**Key characteristics:**
- Event-driven
- Consumption-based pricing
- No charges when idle
**Common use cases:**
- Background jobs
- Event processing
- Automation tasks


## Exam Tip
> As you move from **IaaS → PaaS → SaaS**,  
> **customer responsibility decreases** and **provider responsibility increases**.


## Quick Revision (One-Liners)
- IaaS → maximum control
- PaaS → focus on code
- SaaS → ready-to-use software
- Serverless → pay per execution
