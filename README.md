# Azure Fundamentals Study Notes (AZ-900)

This repository contains my structured study notes for **Microsoft Azure Fundamentals (AZ-900)**. It is part of my ongoing journey into cloud computing, with a focus on building strong foundational knowledge of Microsoft Azure concepts through clear explanations and practical understanding.

The notes in this repository cover core Azure fundamentals such as cloud concepts, Azure architecture, regions and availability, core Azure services, identity and access management, security basics, pricing, and governance. The content is created from a combination of learning sources including official documentation, training courses, and hands-on exploration, and is written in simple language for easy understanding.

This repository is especially useful for:
- Beginners who are new to cloud computing  
- Learners preparing for the **AZ-900 certification exam**  
- Anyone looking for concise, beginner-friendly Azure explanations  

Each topic is organized into individual Markdown (`.md`) files to keep concepts focused and easy to revise. It is recommended to start with the high-level cloud concepts and then move sequentially through Azure services, identity, security, and pricing topics. The notes can be used for regular study, quick revision before exams, or as a reference while doing hands-on labs.

This repository will continue to evolve as I progress in my Azure learning path. Feedback and suggestions are always welcome.
