# Section 1 – Describe Cloud Computing

## 🎯 Purpose of this Section
Explain what cloud computing is, why it exists, and its core models.

---

## 1.1 What is Cloud Computing?

**Definition:**  
Cloud computing is the on-demand delivery of computing resources over the internet with pay-as-you-go pricing.

**Key Points:**
- Rent resources instead of owning hardware
- Scale up or down as needed
- Pay only for what you use

---

## 1.2 Shared Responsibility Model

**Concept:**  
Responsibilities are shared between Microsoft and the customer.

**Remember:**
- More control = more responsibility
- More managed = less responsibility

---

## 1.3 Cloud Deployment Models

### Public Cloud
- Owned by Microsoft
- Shared infrastructure
- Highly scalable

### Private Cloud
- Dedicated to one organization
- More control, higher cost

### Hybrid Cloud
- Combination of public and private
- Most common real-world model

---

## 🧠 Exam Tip
> Hybrid cloud is the most commonly used deployment model in real-world scenarios.

---

##  Quick Revision (One-Liners)
- Cloud = renting computing resources
- Public cloud = shared infrastructure
- Hybrid cloud = mix of public + private
